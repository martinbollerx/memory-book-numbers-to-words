Numbers to Words (Memory Book)

Type a number and get words based on the phonetic alphabet. To learn how to use this system read The Memory Book by Harry Lorayne and Jerry Lucas.

    The phonetic alphabet

    Example: mountain (3212)

    All vowels (a, e, i, o, u) have no value, so mountain is 3212 (m = 3, n = 2, t = 1, n = 2). To remember 3212 just picture a mountain.

    DigitSounds

    Only the sound counts, not the spelling: knife is 28 and phone is 82.
